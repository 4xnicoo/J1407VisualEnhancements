# J1407 Visual Enhancements

J1407 Visual Enhancements adds Scatterer and EVE configurations to J1407 System mod.
<br><br>
<h2>Install Guide</h2>
<h3>Install manually</h3>
<i>(File Size: ~2MB)</i>
<br>
Install via Spacedock <a href="https://spacedock.info/mod/4090/J1407%20Visual%20Enhancements">J1407 Visual Enhancements</a> page or releases tab on GitHub.
<br><br>
Extract ZIP file into your GameData folder.
<br><br>
<b>Dependencies:</b>
<ul>
  <li>Kopernicus</li>
  <li>Kopernicus Expansion</li>
  <li>Singularity</li>
  <li>Scatterer</li>
  <li>Volumetric Clouds (EnviromentalVisualEnhancements)</li>
  <li>ModuleManager</li>
</ul>
